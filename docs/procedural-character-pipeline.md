# GiftVerse — процедурный конвейер персонажа

## Цель

Получать воспроизводимые исходные кадры персонажа из исходного кода, а не вырезать готовую фигуру из референса. Пользовательский референс задаёт художественные требования, но не используется как исходный спрайт.

## Реализация первого прохода

- `tools/generate-researcher-svg.mjs` генерирует SVG-кадры из программно заданных путей и цветов.
- `assets/characters/researcher/procedural/frames/<animation>/<direction>/<frame>.svg` содержит отдельные кадры.
- `assets/characters/researcher/procedural/manifest.json` фиксирует размеры, pivot, направления, состояния, FPS и количество кадров.
- `assets/characters/researcher/procedural/preview.html` даёт предпросмотр и покадровое переключение без установки редактора.\n- `tools/package-researcher-assets.mjs` проверяет все кадры и создаёт `researcher-atlas.json` с метаданными каждой ячейки.\n- GitHub Actions сохраняет весь сгенерированный пакет как скачиваемый artifact на 14 дней.
- Генерация воспроизводима: повторный запуск скрипта создаёт те же кадры.

Поддерживаемые направления: вниз, влево, вправо, вверх. Всего генерируется 264 отдельных SVG-кадра с прозрачным фоном и общей системой координат 128×128, pivot (64,116).

## Важное ограничение

Это первый технический процедурный проход, а не утверждение о завершённом профессиональном арте. Внешность, мелкие детали и художественная согласованность должны быть проверены по предоставленному референсу. Не считать генерацию SVG достаточной для выпуска в игру, пока не пройдены визуальная проверка и интеграционные тесты.

## Следующие этапы

1. Проверить визуальный предпросмотр на телефоне и уточнить пропорции/слои по референсу.
2. Сверить все четыре направления и девять состояний с исходным дизайном.
3. Проверить точку опоры, переключение Idle/Walk/Run, Attack, EchoCast и сохранность карты в игре.
4. После визуальной приёмки подготовить финальный экспорт в целевой формат.
